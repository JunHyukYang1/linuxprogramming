- 실습과제1 -

 예제 8-3에서 SmartTV 클래스의 객체 htv가 생성될 때 먼저 최상위 부모 클래스인 TV 생성자가 먼저 호출됩니다. 그 후 TV 클래스보다 아래에 있는
부모 클래스 WideTV 생성자가 호출되고 마지막으로 SmartTV 생성자가 호출됩니다.
 예제 8-3에서 htv 객체는 문자열 "192.0.0.1"과 정수 32를 인자로 가지는데 이는 객체가 생성될 때 SmartTV 클래스와 해당 클래스가 상속한
부모 클래스들의 각 멤버변수로 전달됩니다. 우선 문자열 "192.0.0.1"은 SmartTV 클래스의 멤버 변수 ipAddr에 저장되고, 정수 32는
SmartTV 클래스의 생성자가 상속한 WidthTV 클래스의 생성자에 전달되고 다시 TV 클래스의 생성자에 전달되어 멤버 변수 size에 전달되어 저장됩니다.


- 실습과제2 -

 실습과제 2번은 예제 8-3을 수정해 기본 생성자를 만들고, 생성된 객체의 멤버 변수에 값을 저장하는 멤버 함수를 만들어 결과를 출력하는 코드입니다.
기본 생성자를 만들 때 WideTV 클래스의 생성자는 TV 클래스의 생성자를 상속하도록 하였고, SmartTV 클래스의 생성자는 WideTV 클래스의 생성자를 상속하도록
만드었습니다. 멤버 변수에 값을 저장하는 멤버 함수는 각 클래스에 set~()의 형태로 각각 size와 videoIn, ipAddr에 값을 저장하는 형태로 만들었습니다.
