

실습과제 2번은 STL 컨테이너 클래스 vector를 이용하여 사용자로부터 정수 4개를 입력 받고 이 중 최대값과 최소값을 출력하는 코드입니다. STL 컨테이너 클래스는 
STL(표준 템플릿 라이브러리)에 정의되어 있는 데이터 저장 템플릿 클래스를 의미합니다. 그 중 vector는 가변 크기의 배열을 일반화한 클래스로 쉽게 말해 배열과
비슷한 역할을 하는 컨테이너 클래스입니다. vector 클래스는 템플릿 클래스이므로 다양한 자료형 변수를 저장할 수 있는데 이번 코드에서는 int 자료형 변수룰
저장하였습니다. 먼저 vector 클래스의 객체를 생성하고, for문을 이용해 사용자로부터 4개의 정수를 받아 객체에 저장합니다. 그리고 vector 클래스의 멤버 함수를

실습과제 4번은 vector 클래스의 객체를 만들어 int 자료형의 변수를 저장하고, 저장된 변수 중 음수만을 제거 후 남은 변수들의 평균값을 구해 출력시키는 코드입니다.
이때 음수를 제거하는 방법으로 컨테이너 클래스에 정의되어 있는 iterator 클래스와 erase(interator it) 함수를 이용하였습니다. iterator 클래스는 컨테이너의 원소를
가리키는 포인터를 관리하는 클래스로, 컨테이너의 원소를 간접적으로 접근할 수 있습니다. *it은 it이 가리키는 원소 값을 의미합니다. 코드의 중간을 보면 for문을 이용한
인덱스 오류 방지 코드가 있는데 이는 동적 배열인 vector 클래스의 객체는 잘못된 인덱스를 사용할 시 런타임 에러가 발생할 수 있기 때문에 이를 방자히기 위한 것입니다.
그 아래로는 erase(iterator it)함수를 이용하여 음수를 제거하고 평균값을 구한 후 출력하였습니다. 아래는 실행 결과입니다.
