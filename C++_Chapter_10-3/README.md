- 실습과제 1

1.
먼저 STL은 Standard Template Library의 약자로, 많은 템플릿 함수와 클래스를 포함한 C++ 표준 템플릿 라이브러리를 의미합니다. STL은 컨테이너 클래스, iterator 클래스,
알고리즘 함수로 구분됩니다. 컨테이너 클래스는 데이터를 저장하는 자료 구조를 구현한 템플릿 클래스로, 그 크기를 자동으로 조절 가능합니다. 컨테이너 클래스의 종류로는
가변 크기의 배열을 일반화한 vector 클래스, 앞뒤 모두 입력이 가능한 deque 클래스. 빠른 삽입 / 삭제가 가능한 list 클래스, 정렬된 순서로 값을 저장하는 집합 클래스인
set 클래스 등이 있습니다. iterator 클래스는 컨테이너 클래스의 내부에 저장된 원소들에 접근하기 위한 클래스로, 컨테이너 원소에 대한 포인터를 저장하는 클래스입니다.
iterator 클래스는 각 컨테이너 클래스 안에 따로 정의되어 있고, 포인터와 유사한 기능과 사용법을 가진 클래스입니다. iterator 클래스를 사용할 때에는 어떤 컨테이너
클래스에 소속되어 있는지 명시해야 합니다. 마지막으로 알고리즘 함수는 컨테이터의 원소에 대한 복사, 검색, 삭제, 정렬 등을 구현한 템플릿 함수입니다. 이 함수는
컨테이너의 멤버 함수로 정의된 것이 아닌 전역함수로 정의되어 있습니다. 알고리즘 함수의 종류에는 복사 기능의 copy, 검색 기능의 search, 삭제 기능의 remove 등이 있습니다.
컨테이너 클래스와 알고리즘 함수의 경우 코드 내에서 사용하기 위해서는 해당하는 헤더 파일을 포함 시켜야 합니다. iterator 클래스는 위에서 말했 듯이 각 컨테이너 클래스
안에 따로 정의되어 있으므로 컨테이너 클래스의 헤더 파일을 포함시켰으면 따로 해야할 것은 없습니다.

2.
포인터와 iterator는 둘 다 특정 데이터의 주소를 가리키고, 이를 통해 간접적으로 데이터를 읽거나 수정하는 기능을 가졌습니다. 둘 모두 * 연산자를 사용하여 가리키는
데이터를 참조하여 값을 수정하기도 합니다. 그러나 포인터는 주로 배열에 사용하여 값들을 관리하고, iterator 클래스는 주로 STL 컨테이너 클래스에 사용하여 데이터의
범위를 안전하게 처리합니다. 쉽개 말해 포인터는 비교적 낮은 수준의 데이터를 다루고 iterator 클래스는 보다 복잡한 수준의 데이터를 다룹니다.

3.
vector 클래스의 erase 함수는 erase(iterator it)와 같은 형태로 사용하고, insert 함수는 insert(iterator it, element)와 같은 형태로 사용합니다. 이때 두 함수의
매개변수로 사용된 iterator it는 iterator 클래스의 객체 it가 가리키는 원소를 의미하는 것으로, erase 함수의 경우 매개변수를 통해 it이 가리키는 원소를 제거합니다.
insert 함수는 매개변수 it을 통해 위치를 지정하고, element 매개변수를 사용해 지정한 위치에 원하는 값을 저장하는 기능을 수행합니다. erase 함수의 경우 리턴값은
제거한 원소의 다음 원소를 가리키는 반복자 it입니다. 만약 다음 원소가 존재하지 않는다면 반복자는 해당 클래스 객체의 end()를 가리킵니다. insert 함수의 리턴값은
값을 저장한 원소를 가리키는 반복자 it을 반환합니다.
