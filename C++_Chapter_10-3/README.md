

실습과제 2번은 STL 컨테이너 클래스 vector를 이용하여 사용자로부터 정수 4개를 입력 받고 이 중 최대값과 최소값을 출력하는 코드입니다. STL 컨테이너 클래스는 
STL(표준 템플릿 라이브러리)에 정의되어 있는 데이터 저장 템플릿 클래스를 의미합니다. 그 중 vector는 가변 크기의 배열을 일반화한 클래스로 쉽게 말해 배열과
비슷한 역할을 하는 컨테이너 클래스입니다. vector 클래스는 템플릿 클래스이므로 다양한 자료형 변수를 저장할 수 있는데 이번 코드에서는 int 자료형 변수룰
저장하였습니다. 먼저 vector 클래스의 객체를 생성하고, for문을 이용해 사용자로부터 4개의 정수를 받아 객체에 저장합니다. 그리고 vector 클래스의 멤버 함수를
이용해 최대값과 최소값을 구하고 이를 출력하였습니다. 아래는 실행 결과입니다.
